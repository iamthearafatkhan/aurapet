Frequently Asked Questions

How do I reset the app to see the setup screen again?

Press Windows Key + R, type %appdata%\AuraPet, and delete the settings.json file. Restart the app.

Do I need to install Ollama or Python?

No! AuraPet automatically downloads the Ollama engine into your AppData folder during the first setup.

Where are the AI models stored?

They are stored in %USERPROFILE%\.ollama\models. If you use the official Ollama app, they share the same models.

The chat window is transparent over YouTube videos.

This is a known Electron/Windows GPU compositing bug. It does not affect functionality. We are looking into a fix for future updates.
